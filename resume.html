How I Build

01

Start with the Spark

What should this feel like to play? I sketch the core loop on paper before opening the engine.

02

Prototype Fast

A playable build in days. If it isn't fun with grey boxes, no amount of art will save it.

03

Design the Loop

Pacing, progression, tension and relief — the loop players can't stop playing.

04

Build It Right

Clean C# in Unity, Blueprints in Unreal. Component-based, readable, no surprises.

05

Test & Iterate

Builds in real players' hands early. Their first reaction beats a month of polish.

06

Ship It Smooth

Profiling, bug hunting, store assets, trailers — the last 10% that makes it a product.
